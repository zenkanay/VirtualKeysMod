# VirtualKeys (Fabric 1.21.11)

画面上にカスタマイズ可能な仮想キーボードパネルを表示し、マウス操作やキー入力支援を行う Minecraft 1.21.11 向け Fabric Mod です。

---

## 📋 Requirements (必要環境)

* **Minecraft**: `1.21.11`
* **Mod Loader**: `Fabric`
* **Java**: `21` 以上
* **Dependencies**:
  * [Fabric API](https://modrinth.com/mod/fabric-api) (Required)

---

## ✨ Features (主な機能)

* **仮想キーパネル表示**:
  * 画面上に自由な配置・整列（左寄せ・中央・右寄せなど）で仮想キーを表示。
  * 移動、ジャンプ、ダッシュ、スニークなどをパネルを開いたままシームレスに操作可能。
* **キーカスタマイズ**:
  * 画面上の歯車アイコンからキー名の編集、キー配置の変更が可能。
* **シームレスな操作性**:
  * 歩きながらのパネル開閉に対応。

---

## ⌨️ Controls (デフォルト操作)

* **`V` キー**: 仮想キーパネルを開く / 閉じる
* **`H` キー**: パネルのホールド表示（押している間だけ表示）
